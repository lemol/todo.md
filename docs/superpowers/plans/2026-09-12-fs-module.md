# fs Module Implementation Plan (Plan 3 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `@lemol/todo-md/fs`: `FsTodoStore`, the reference `TodoStore` that keeps a todo.md list as a directory of Markdown files and passes the same conformance suite as `MemoryTodoStore`. It also covers discovery (`findListRoot`), list creation (`initList`) and normalization on request.

**Architecture:**
- **Reads** take a snapshot of the list (`TODO.md`, the linked task files, the done directory, and task file names) and never write.
- **Every mutation** takes an advisory lock file, normalizes the list (spec §2.11), reads a fresh snapshot, and applies the operation's edits. The edits use the `markdown` module's minimal-diff functions, in the crash-safe order of spec §2.10.
- **Files** are accessed through Effect's `FileSystem` and `Path` services, and written atomically (temporary file, then rename).

**Tech Stack:** Bun 1.4, TypeScript 7, Effect `4.0.0-rc.108` (`FileSystem`, `Path`, `Clock`, `DateTime`, `Layer`), `@effect/platform-bun` (tests only, for `BunServices.layer`), `bun:test`, Biome.

## Decisions this plan makes

Task 5 and Task 6 record them in the code and docs.

- **Pin `@effect/platform-node-shared` to `4.0.0-rc.108`** (as a dependency and in `overrides`). `@effect/platform-bun@4.0.0-rc.108` depends on it with the range `^4.0.0-rc.108`, which resolves to a newer release candidate that imports modules missing from `effect@4.0.0-rc.108`. Today, importing `@effect/platform-bun` fails on a fresh install.
- **Bounded scanning.** Orphan and used-ID scanning look only directly in `tasks_dir` and its group directories (plus `done_dir` recursively). A list whose `TODO.md` sits at a project root therefore never walks the whole project. Spec §2.7 and §2.8 are clarified to say so.
- **No `broken-link` for an interrupted operation.** An interrupted reopen leaves an item whose file does not exist yet. It is reported only as `interrupted-completion`, because that diagnostic explains it and the next change repairs it.
- **Conformance fix.** The case "update allows a dependency on a task that no longer exists" assumed a removed task's ID is never reused. Spec §1.2 allows reuse once no record remains, and `FsTodoStore` derives IDs from what is on disk. The case now removes the task after adding the other one.
- **Checked items are the newest done tasks.** `listDone` lists checked-but-unswept items first, since their completion time is not known yet, and then done files, newest first.

```ts
import { BunServices } from "@effect/platform-bun"
import { Context, Effect, FileSystem, Layer, Path } from "effect"
import { type Files, makeFiles } from "../../src/fs/files.ts"

export const md = (...lines: string[]) => `${lines.join("\n")}\n`

/** Direct access to a temporary directory's files, by root-relative path. */
export class Disk extends Context.Service<
  Disk,
  {
    readonly root: string
    read(path: string): Effect.Effect<string>
    write(path: string, text: string): Effect.Effect<void>
    exists(path: string): Effect.Effect<boolean>
    /** Sets a file's modification time. */
    setModified(path: string, time: Date): Effect.Effect<void>
    /** Every file below the root, sorted. */
    tree(): Effect.Effect<ReadonlyArray<string>>
  }
>()("test/fs/Disk") {}

/** A temporary directory holding `files` (root-relative path → text), removed afterwards. */
export const diskWith = (files: Readonly<Record<string, string>>): Layer.Layer<Disk> =>
  Layer.effect(
    Disk,
    Effect.gen(function* () {
      const fs = yield* FileSystem.FileSystem
      const path = yield* Path.Path
      const root = yield* fs.makeTempDirectoryScoped({ prefix: "todo-md-" }).pipe(Effect.orDie)
      const absolute = (relative: string) => path.join(root, relative)
      const disk = Disk.of({
        root,
        read: (relative) => fs.readFileString(absolute(relative)).pipe(Effect.orDie),
        write: (relative, text) =>
          fs
            .makeDirectory(path.dirname(absolute(relative)), { recursive: true })
            .pipe(Effect.andThen(fs.writeFileString(absolute(relative), text)), Effect.orDie),
        exists: (relative) => fs.exists(absolute(relative)).pipe(Effect.orDie),
        setModified: (relative, time) =>
          fs.utimes(absolute(relative), time, time).pipe(Effect.orDie),
        tree: () =>
          fs.readDirectory(root, { recursive: true }).pipe(
            Effect.flatMap((entries) =>
              Effect.forEach(entries, (entry) =>
                Effect.map(fs.stat(absolute(entry)), (info) =>
                  info.type === "File" ? [entry] : [],
                ),
              ),
            ),
            Effect.map((entries) => entries.flat().sort()),
            Effect.orDie,
          ),
      })
      for (const [relative, text] of Object.entries(files)) yield* disk.write(relative, text)
      return disk
    }),
  ).pipe(Layer.provide(BunServices.layer))

/** `Files` for the test directory. */
export const filesOnDisk: Effect.Effect<Files, never, Disk> = Effect.gen(function* () {
  return yield* makeFiles((yield* Disk).root).pipe(Effect.provide(BunServices.layer))
})
```

```ts
import { Effect, FileSystem, Path, type PlatformError } from "effect"
import { StoreError } from "../spec/index.ts"

/**
 * File access for one list, by root-relative path. Every failure becomes a
 * `StoreError`; a missing file is not a failure where the caller can expect it.
 */
export interface Files {
  readonly root: string
  /** The file's text, or `undefined` if it does not exist. */
  readonly read: (path: string) => Effect.Effect<string | undefined, StoreError>
  /** Writes atomically (temporary file, then rename), creating directories as needed. */
  readonly write: (path: string, text: string) => Effect.Effect<void, StoreError>
  /** Deletes a file; a missing file is fine. */
  readonly remove: (path: string) => Effect.Effect<void, StoreError>
  /** Moves a file or directory, creating the target's parent directories. */
  readonly move: (from: string, to: string) => Effect.Effect<void, StoreError>
  readonly exists: (path: string) => Effect.Effect<boolean, StoreError>
  /** Root-relative paths of the entries in `dir` (all files below it when `recursive`); `[]` if it is missing. */
  readonly list: (
    dir: string,
    options?: { readonly recursive?: boolean },
  ) => Effect.Effect<ReadonlyArray<string>, StoreError>
}

const isNotFound = (error: PlatformError.PlatformError): boolean => error.reason._tag === "NotFound"

const fail = (action: string) => (error: PlatformError.PlatformError) =>
  new StoreError({ message: `could not ${action}: ${error.message}`, cause: error })

export const makeFiles = (
  root: string,
): Effect.Effect<Files, never, FileSystem.FileSystem | Path.Path> =>
  Effect.gen(function* () {
    const fs = yield* FileSystem.FileSystem
    const path = yield* Path.Path
    const absolute = (relative: string) => path.join(root, relative)
    const makeParent = (target: string) =>
      fs.makeDirectory(path.dirname(target), { recursive: true })

    return {
      root,
      read: (relative) =>
        fs
          .readFileString(absolute(relative))
          .pipe(
            Effect.catch((error) =>
              isNotFound(error)
                ? Effect.succeed(undefined)
                : Effect.fail(fail(`read ${relative}`)(error)),
            ),
          ),
      write: (relative, text) => {
        const target = absolute(relative)
        const temporary = `${target}.${Math.random().toString(36).slice(2)}.tmp`
        return makeParent(target).pipe(
          Effect.andThen(fs.writeFileString(temporary, text)),
          Effect.andThen(fs.rename(temporary, target)),
          Effect.mapError(fail(`write ${relative}`)),
        )
      },
      remove: (relative) =>
        fs
          .remove(absolute(relative))
          .pipe(
            Effect.catch((error) =>
              isNotFound(error) ? Effect.void : Effect.fail(fail(`remove ${relative}`)(error)),
            ),
          ),
      move: (from, to) =>
        makeParent(absolute(to)).pipe(
          Effect.andThen(fs.rename(absolute(from), absolute(to))),
          Effect.mapError(fail(`move ${from} to ${to}`)),
        ),
      exists: (relative) =>
        fs.exists(absolute(relative)).pipe(Effect.mapError(fail(`check ${relative}`))),
      list: (dir, options) =>
        fs.readDirectory(absolute(dir), { recursive: options?.recursive ?? false }).pipe(
          Effect.map((entries) =>
            entries.map((entry) => path.join(dir, entry).split(path.sep).join("/")).sort(),
          ),
          Effect.catch((error) =>
            isNotFound(error) ? Effect.succeed([]) : Effect.fail(fail(`list ${dir}`)(error)),
          ),
        ),
    }
  })
```

Create `src/fs/lock.ts`:

```ts
import { Clock, Duration, Effect, FileSystem, Option, Path, type PlatformError } from "effect"
import { StoreError } from "../spec/index.ts"

export interface LockOptions {
  /** How long to wait for another process's lock before failing. */
  readonly timeout: Duration.Input
  /** A lock file older than this was left by a crashed process and is taken over. */
  readonly staleAfter: Duration.Input
  /** How long to wait between attempts. */
  readonly retryEvery: Duration.Input
}

export const defaultLockOptions: LockOptions = {
  timeout: "10 seconds",
  staleAfter: "30 seconds",
  retryEvery: "50 millis",
}

export const lockFile = ".todo.lock"

/** Runs an effect while holding the list's lock. */
export type Lock = <A, E, R>(effect: Effect.Effect<A, E, R>) => Effect.Effect<A, E | StoreError, R>

const alreadyExists = (error: PlatformError.PlatformError) => error.reason._tag === "AlreadyExists"

/**
 * The list's advisory lock: `<root>/.todo.lock`, created exclusively, so
 * concurrent processes (typically agents) cannot lose each other's writes.
 * The lock is released however the locked effect ends.
 */
export const makeLock = (
  root: string,
  options: LockOptions = defaultLockOptions,
): Effect.Effect<Lock, never, FileSystem.FileSystem | Path.Path> =>
  Effect.gen(function* () {
    const fs = yield* FileSystem.FileSystem
    const lock = (yield* Path.Path).join(root, lockFile)
    const failure = (error: PlatformError.PlatformError) =>
      new StoreError({ message: `could not lock the list: ${error.message}`, cause: error })

    const acquire = Effect.gen(function* () {
      const deadline = (yield* Clock.currentTimeMillis) + Duration.toMillis(options.timeout)
      while (true) {
        const created = yield* fs.writeFileString(lock, "", { flag: "wx" }).pipe(
          Effect.as(true),
          Effect.catch((error) =>
            alreadyExists(error) ? Effect.succeed(false) : Effect.fail(failure(error)),
          ),
        )
        if (created) return
        const now = yield* Clock.currentTimeMillis
        const modified = Option.flatMap(yield* Effect.option(fs.stat(lock)), (info) => info.mtime)
        const age = Option.isSome(modified) ? now - modified.value.getTime() : 0
        if (age > Duration.toMillis(options.staleAfter)) {
          yield* Effect.ignore(fs.remove(lock))
          continue
        }
        if (now >= deadline) {
          return yield* new StoreError({
            message: `the list is locked by another process (${lock})`,
          })
        }
        yield* Effect.sleep(options.retryEvery)
      }
    })

    return (effect) =>
      Effect.acquireUseRelease(
        acquire,
        () => effect,
        () => Effect.ignore(fs.remove(lock)),
      )
  })
```

The lock compares `Clock.currentTimeMillis` with the file's modification time, so it assumes the real clock. Under `TestClock` an uncontended lock works, because it never sleeps or checks staleness. That's why the lock's own tests use the real clock.

```ts
import { Effect } from "effect"
import {
  allItems,
  basename,
  fileTask,
  groupSlug,
  inlineTask,
  joinPath,
  parseId,
  parseTaskFile,
  parseTodoFile,
  staleLinkText,
  type TaskFile,
  type TodoFile,
  type TodoItem,
  type TodoSection,
} from "../markdown/index.ts"
import { type Diagnostic, StoreError, type Task, type TaskId, unique } from "../spec/index.ts"
import type { Files } from "./files.ts"

export const todoPath = "TODO.md"

/** An item in `TODO.md` that has an ID, with its task file when it is linked. */
export interface Entry {
  readonly id: TaskId
  readonly item: TodoItem
  readonly section: TodoSection
  /** The linked task file's text and parse, when it exists. */
  readonly source: string | undefined
  readonly file: TaskFile | undefined
}

/** A file in the done directory. */
export interface DoneEntry {
  readonly id: TaskId
  readonly path: string
  readonly source: string
  readonly file: TaskFile
}

/** Everything a list holds on disk, read at one moment. */
export interface Snapshot {
  /** `TODO.md` as read. */
  readonly source: string
  readonly todo: TodoFile
  /** Items with an ID, in document order. */
  readonly entries: ReadonlyArray<Entry>
  readonly done: ReadonlyArray<DoneEntry>
  /** Every ID in use: items, task file names and done file names (spec §2.7). */
  readonly usedIds: ReadonlyArray<TaskId>
  /** Frontmatter titles of linked task files, by path. */
  readonly titles: ReadonlyMap<string, string>
  readonly diagnostics: ReadonlyArray<Diagnostic>
}

const taskFileName = /^\d+-.*\.md$/

const idOfFile = (path: string): TaskId | undefined =>
  taskFileName.test(basename(path)) ? parseId(basename(path).split("-")[0] ?? "") : undefined

const isUnder = (path: string, dir: string) => dir === "." || path.startsWith(`${dir}/`)

const title = (entry: Entry) => entry.file?.title ?? entry.item.title

/** Whether a done file has this ID and title: a completion was interrupted (spec §2.10). */
const matchesDone = (done: ReadonlyArray<DoneEntry>, id: TaskId, title: string): boolean =>
  done.some((entry) => entry.id === id && (entry.file.title ?? "") === title)

/** An open entry whose completion was interrupted: a done file has its ID and title. */
export const isInterrupted = (snapshot: Snapshot, entry: Entry): boolean =>
  matchesDone(snapshot.done, entry.id, title(entry))

/** The model task for an entry: done when its box is checked. */
export const entryTask = (entry: Entry): Task => {
  const status = entry.item.checked ? "done" : "open"
  return entry.item.linked
    ? fileTask(entry.id, entry.file ?? parseTaskFile("", entry.item.path ?? ""), {
        title: entry.item.title,
        status,
        group: entry.section.name,
      })
    : inlineTask(entry.item, entry.id, entry.section.name)
}

export const doneTask = (done: DoneEntry): Task =>
  fileTask(done.id, done.file, {
    title: basename(done.path).replace(/^\d+-/, "").replace(/\.md$/, ""),
    status: "done",
    group: done.file.group,
  })

/** Reads the whole list. Never writes. */
export const readSnapshot = (files: Files): Effect.Effect<Snapshot, StoreError> =>
  Effect.gen(function* () {
    const source = yield* files.read(todoPath)
    if (source === undefined) {
      return yield* new StoreError({ message: `no ${todoPath} in ${files.root}` })
    }
    const todo = parseTodoFile(source)
    const { tasksDir, doneDir } = todo.config
    const diagnostics: Diagnostic[] = [...todo.diagnostics]

    const done: DoneEntry[] = []
    for (const path of yield* files.list(doneDir, { recursive: true })) {
      const id = idOfFile(path)
      const text = id === undefined ? undefined : yield* files.read(path)
      if (id === undefined || text === undefined) continue
      const file = parseTaskFile(text, path)
      diagnostics.push(...file.diagnostics)
      done.push({ id, path, source: text, file })
    }

    const entries: Entry[] = []
    for (const section of todo.sections) {
      for (const item of section.items) {
        if (item.id === undefined) continue
        const path = item.path
        const text = path === undefined ? undefined : yield* files.read(path)
        const file =
          path === undefined || text === undefined ? undefined : parseTaskFile(text, path)
        const entry: Entry = { id: item.id, item, section, source: text, file }
        const location = { taskId: item.id, file: todoPath, line: item.start + 1 }
        if (file !== undefined) {
          diagnostics.push(...file.diagnostics)
          const stale = file.title === undefined ? undefined : staleLinkText(item, file.title)
          if (stale !== undefined) diagnostics.push(stale)
        }
        if (matchesDone(done, item.id, title(entry))) {
          diagnostics.push({
            severity: "warning",
            code: "interrupted-completion",
            message: `task ${item.id} is both open and done; the next change finishes completing it`,
            ...location,
          })
        } else if (item.linked && path !== undefined && text === undefined) {
          diagnostics.push({
            severity: "error",
            code: "broken-link",
            message: `${path} does not exist`,
            ...location,
          })
        }
        entries.push(entry)
      }
    }

    // Task files live in the tasks directory and its group directories (spec §2.8).
    const taskDirs = new Set([
      tasksDir,
      ...todo.sections.flatMap((s) =>
        s.name === undefined ? [] : [joinPath(tasksDir, groupSlug(s.name))],
      ),
    ])
    const taskFiles: string[] = []
    for (const dir of taskDirs) {
      for (const path of yield* files.list(dir)) {
        if (idOfFile(path) !== undefined && !isUnder(path, doneDir)) taskFiles.push(path)
      }
    }
    const linked = new Set(
      allItems(todo).flatMap((item) => (item.path === undefined ? [] : [item.path])),
    )
    for (const path of taskFiles.filter((candidate) => !linked.has(candidate))) {
      diagnostics.push({
        severity: "warning",
        code: "orphan-file",
        message: `no item links to ${path}`,
        file: path,
      })
    }

    // Each ID names one task: across items, and between items and done files
    // (except an interrupted completion, reported above).
    const seen = new Map<TaskId, string>()
    const claim = (id: TaskId, where: string) => {
      const first = seen.get(id)
      if (first === undefined) seen.set(id, where)
      else {
        diagnostics.push({
          severity: "error",
          code: "duplicate-id",
          message: `task ${id} appears in ${first} and ${where}`,
          taskId: id,
        })
      }
    }
    for (const entry of entries) claim(entry.id, `${todoPath}:${entry.item.start + 1}`)
    for (const entry of done) {
      const open = entries.find((candidate) => candidate.id === entry.id)
      if (open === undefined || !matchesDone([entry], open.id, title(open)))
        claim(entry.id, entry.path)
    }

    return {
      source,
      todo,
      entries,
      done,
      usedIds: unique([
        ...entries.map((entry) => entry.id),
        ...done.map((entry) => entry.id),
        ...taskFiles.flatMap((path) => idOfFile(path) ?? []),
      ]),
      titles: new Map(
        entries.flatMap((entry) =>
          entry.item.path !== undefined && entry.file?.title !== undefined
            ? [[entry.item.path, entry.file.title] as const]
            : [],
        ),
      ),
      diagnostics,
    }
  })
```

```ts
import { DateTime, Effect } from "effect"
import {
  fitsInline,
  formatTaskFile,
  inlineItemFor,
  type ListConfig,
  linkedItemFor,
  removeItem,
  taskFileFor,
  taskPath,
  updateTaskFile,
} from "../markdown/index.ts"
import type { StoreError, Task } from "../spec/index.ts"
import type { Files } from "./files.ts"
import { type Entry, entryTask, type Snapshot, todoPath } from "./snapshot.ts"

/**
 * The `TODO.md` lines for an open task. A task that cannot stay inline, or
 * already has a file at `path`, gets its task file (re)written (spec §2.9).
 */
export const itemLinesFor = (
  files: Files,
  config: ListConfig,
  task: Task,
  path?: string,
): Effect.Effect<string[], StoreError> =>
  Effect.gen(function* () {
    if (path === undefined && fitsInline(task)) return inlineItemFor(task)
    const target = path ?? taskPath(config.tasksDir, task.group, task.id, task.title)
    yield* files.write(target, formatTaskFile(taskFileFor(task)))
    return linkedItemFor(task, target)
  })

/**
 * Completes an entry in the order spec §2.10 requires: write the done file
 * (the commit point), delete the original task file, then remove the item.
 */
export const completeEntry = (
  files: Files,
  snapshot: Snapshot,
  entry: Entry,
): Effect.Effect<Task, StoreError> =>
  Effect.gen(function* () {
    const group = entry.section.name
    const done: Task = {
      ...entryTask(entry),
      status: "done",
      completedAt: yield* DateTime.now,
      group,
    }
    const donePath = taskPath(snapshot.todo.config.doneDir, group, entry.id, done.title)
    const source =
      entry.source === undefined
        ? formatTaskFile(taskFileFor(done))
        : updateTaskFile(entry.source, {
            group: group ?? null,
            completedAt: done.completedAt ?? null,
            ...(entry.file?.title === undefined ? { title: done.title } : {}),
          })
    yield* files.write(donePath, source)
    const original = entry.item.path
    if (entry.item.linked && original !== undefined && original !== donePath)
      yield* files.remove(original)
    yield* files.write(todoPath, removeItem(snapshot.todo, entry.item))
    return done
  })
```

```ts
import { Effect } from "effect"
import { normalize, removeItem } from "../markdown/index.ts"
import type { StoreError, TaskId } from "../spec/index.ts"
import type { Files } from "./files.ts"
import { isInterrupted, readSnapshot, todoPath } from "./snapshot.ts"
import { completeEntry } from "./writing.ts"

/** What normalization did. */
export interface NormalizeReport {
  /** IDs given to items that had none. */
  readonly assigned: ReadonlyArray<TaskId>
  /** Interrupted completions that were finished. */
  readonly finished: ReadonlyArray<TaskId>
  /** Checked items that were completed. */
  readonly swept: ReadonlyArray<TaskId>
}

/**
 * Brings a hand-edited list back to canonical state (spec §2.11): assigns IDs
 * and syncs link text, finishes interrupted completions, then completes
 * checked items. Call it while holding the lock.
 */
export const normalizeList = (files: Files): Effect.Effect<NormalizeReport, StoreError> =>
  Effect.gen(function* () {
    const first = yield* readSnapshot(files)
    const { text, assigned } = normalize(first.todo, {
      usedIds: first.usedIds,
      titles: first.titles,
    })
    if (text !== first.source) yield* files.write(todoPath, text)

    const finished: TaskId[] = []
    while (true) {
      const snapshot = yield* readSnapshot(files)
      const entry = snapshot.entries.find((candidate) => isInterrupted(snapshot, candidate))
      if (entry === undefined) break
      yield* files.write(todoPath, removeItem(snapshot.todo, entry.item))
      const leftover = entry.item.path
      if (
        entry.item.linked &&
        leftover !== undefined &&
        !snapshot.done.some((d) => d.path === leftover)
      ) {
        yield* files.remove(leftover)
      }
      finished.push(entry.id)
    }

    const swept: TaskId[] = []
    while (true) {
      const snapshot = yield* readSnapshot(files)
      const entry = snapshot.entries.find((candidate) => candidate.item.checked)
      if (entry === undefined) break
      yield* completeEntry(files, snapshot, entry)
      swept.push(entry.id)
    }
    return { assigned, finished, swept }
  })
```

```ts
/**
 * The reference file-system `TodoStore`: a list directory with `TODO.md`,
 * task files and a done directory (spec Part 2). Reads never write; every
 * mutation takes the lock, normalizes the list, then applies its edits.
 */

import { DateTime, Effect, type FileSystem, Layer, type Path } from "effect"
import {
  allItems,
  basename,
  dirname,
  formatLinkedItem,
  formatTaskFile,
  groupSlug,
  insertItem,
  joinPath,
  linkedItemFor,
  nextId,
  parseTodoFile,
  prependComment,
  removeItem,
  renameSection,
  replaceItem,
  setItemHead,
  type TaskFileChanges,
  type TodoFile,
  taskFileFor,
  taskPath,
  updateTaskFile,
} from "../markdown/index.ts"
import {
  allCapabilities,
  type Comment,
  CommentInput,
  ensureAcyclic,
  GroupNotFound,
  InvalidTransition,
  Label,
  Placement,
  type Task,
  type TaskId,
  TaskInput,
  TaskNotFound,
  TaskPatch,
  type TodoList,
  TodoStore,
  unique,
  ValidationError,
  validate,
} from "../spec/index.ts"
import { type Files, makeFiles } from "./files.ts"
import { defaultLockOptions, type LockOptions, makeLock } from "./lock.ts"
import { normalizeList } from "./normalization.ts"
import {
  doneTask,
  type Entry,
  entryTask,
  isInterrupted,
  readSnapshot,
  type Snapshot,
  todoPath,
} from "./snapshot.ts"
import { completeEntry, itemLinesFor } from "./writing.ts"

export interface Options {
  /** Absolute path of the list root: the directory that contains `TODO.md`. */
  readonly root: string
  readonly lock?: Partial<LockOptions>
}

/** Open entries as the model sees them: not checked and not mid-completion. */
const openEntries = (snapshot: Snapshot): ReadonlyArray<Entry> =>
  snapshot.entries.filter((entry) => !entry.item.checked && !isInterrupted(snapshot, entry))

const toList = (snapshot: Snapshot): TodoList => {
  const open = openEntries(snapshot)
  const [ungrouped, ...groups] = snapshot.todo.sections
  const tasksOf = (name: string | undefined) =>
    open.filter((entry) => entry.section.name === name).map(entryTask)
  return {
    title: snapshot.todo.title,
    description: snapshot.todo.description,
    ungrouped: ungrouped === undefined ? [] : tasksOf(undefined),
    groups: groups.map((group) => ({
      name: group.name ?? "",
      description: group.description,
      tasks: tasksOf(group.name),
    })),
  }
}

const findTask = (snapshot: Snapshot, id: TaskId): Effect.Effect<Task, TaskNotFound> => {
  const entry = snapshot.entries.find(
    (candidate) => candidate.id === id && !isInterrupted(snapshot, candidate),
  )
  if (entry !== undefined) return Effect.succeed(entryTask(entry))
  const done = snapshot.done.find((candidate) => candidate.id === id)
  return done === undefined ? Effect.fail(new TaskNotFound({ id })) : Effect.succeed(doneTask(done))
}

const findOpen = (
  snapshot: Snapshot,
  id: TaskId,
  operation: string,
): Effect.Effect<Entry, TaskNotFound | InvalidTransition> => {
  const entry = openEntries(snapshot).find((candidate) => candidate.id === id)
  if (entry !== undefined) return Effect.succeed(entry)
  const known = snapshot.done.some((d) => d.id === id) || snapshot.entries.some((e) => e.id === id)
  return Effect.fail(
    known ? new InvalidTransition({ id, status: "done", operation }) : new TaskNotFound({ id }),
  )
}

const allTasks = (snapshot: Snapshot): ReadonlyArray<Task> => [
  ...snapshot.entries.map(entryTask),
  ...snapshot.done.map(doneTask),
]

/** Resolves a placement against `todo`, which must not contain the task being placed. */
const resolve = (
  todo: TodoFile,
  placement: Placement,
): Effect.Effect<
  { readonly group: string | undefined; readonly index: number },
  TaskNotFound | ValidationError
> => {
  if (placement.before !== undefined && placement.after !== undefined) {
    return Effect.fail(
      new ValidationError({ issues: ["a placement takes before or after, not both"] }),
    )
  }
  const anchorId = placement.before ?? placement.after
  if (anchorId === undefined) {
    const section = todo.sections.find((candidate) => candidate.name === placement.group)
    return Effect.succeed({ group: placement.group, index: section?.items.length ?? 0 })
  }
  for (const section of todo.sections) {
    const index = section.items.findIndex((item) => item.id === anchorId && !item.checked)
    if (index === -1) continue
    if (placement.group !== undefined && placement.group !== section.name) {
      return Effect.fail(
        new ValidationError({ issues: [`task ${anchorId} is not in group ${placement.group}`] }),
      )
    }
    return Effect.succeed({
      group: section.name,
      index: placement.before === undefined ? index + 1 : index,
    })
  }
  return Effect.fail(new TaskNotFound({ id: anchorId }))
}

const applyPatch = (task: Task, patch: TaskPatch): Task => ({
  ...task,
  title: patch.title ?? task.title,
  description: patch.description ?? task.description,
  tags: patch.tags === undefined ? task.tags : unique(patch.tags),
  assignee: patch.assignee === undefined ? task.assignee : (patch.assignee ?? undefined),
  dependsOn: patch.dependsOn === undefined ? task.dependsOn : unique(patch.dependsOn),
  extra: patch.extra ?? task.extra,
})

const changesOf = (patch: TaskPatch): TaskFileChanges => ({
  ...(patch.title === undefined ? {} : { title: patch.title }),
  ...(patch.description === undefined ? {} : { description: patch.description }),
  ...(patch.tags === undefined ? {} : { tags: unique(patch.tags) }),
  ...(patch.assignee === undefined ? {} : { assignee: patch.assignee }),
  ...(patch.dependsOn === undefined ? {} : { dependsOn: unique(patch.dependsOn) }),
  ...(patch.extra === undefined ? {} : { extra: patch.extra }),
})

/** The directory a task file of `group` lives in by convention. */
const groupDir = (tasksDir: string, group: string | undefined) =>
  dirname(taskPath(tasksDir, group, "0", "x"))

const byCompletion = (a: Task, b: Task) =>
  (b.completedAt === undefined ? 0 : DateTime.toEpochMillis(b.completedAt)) -
  (a.completedAt === undefined ? 0 : DateTime.toEpochMillis(a.completedAt))

const makeStore = (files: Files, options: Options) =>
  Effect.gen(function* () {
    const lock = yield* makeLock(files.root, { ...defaultLockOptions, ...options.lock })
    const read = readSnapshot(files)
    const writeTodo = (text: string) => files.write(todoPath, text)

    /** Runs `f` under the lock, on a freshly normalized snapshot (spec §2.11). */
    const mutate = <A, E>(f: (snapshot: Snapshot) => Effect.Effect<A, E>) =>
      lock(normalizeList(files).pipe(Effect.andThen(read), Effect.flatMap(f)))

    return TodoStore.of({
      capabilities: allCapabilities,

      load: () => Effect.map(read, toList),

      get: (id) => Effect.flatMap(read, (snapshot) => findTask(snapshot, id)),

      listDone: () =>
        Effect.map(read, (snapshot) => [
          ...snapshot.entries
            .filter((entry) => entry.item.checked && !isInterrupted(snapshot, entry))
            .map(entryTask),
          ...snapshot.done.map(doneTask).sort(byCompletion),
        ]),

      add: (input, placement = {}) =>
        Effect.all([validate(TaskInput, input), validate(Placement, placement)]).pipe(
          Effect.flatMap(([valid, where]) =>
            mutate((snapshot) =>
              Effect.gen(function* () {
                const target = yield* resolve(snapshot.todo, where)
                const task: Task = {
                  id: nextId(snapshot.usedIds),
                  title: valid.title,
                  description: valid.description ?? "",
                  status: "open",
                  tags: unique(valid.tags ?? []),
                  assignee: valid.assignee,
                  dependsOn: unique(valid.dependsOn ?? []),
                  comments: [],
                  group: target.group,
                  extra: valid.extra ?? {},
                }
                yield* ensureAcyclic([...allTasks(snapshot), task])
                const lines = yield* itemLinesFor(files, snapshot.todo.config, task)
                yield* writeTodo(insertItem(snapshot.todo, target.group, target.index, lines))
                return task
              }),
            ),
          ),
        ),

      update: (id, patch) =>
        validate(TaskPatch, patch).pipe(
          Effect.flatMap((valid) =>
            mutate((snapshot) =>
              Effect.gen(function* () {
                const updated = applyPatch(yield* findTask(snapshot, id), valid)
                yield* ensureAcyclic(
                  allTasks(snapshot).map((task) => (task.id === id ? updated : task)),
                )
                const done = snapshot.done.find((candidate) => candidate.id === id)
                if (done !== undefined) {
                  yield* files.write(done.path, updateTaskFile(done.source, changesOf(valid)))
                  return updated
                }
                const entry = snapshot.entries.find((candidate) => candidate.id === id)
                if (entry === undefined) return yield* new TaskNotFound({ id })
                const { item } = entry
                if (!item.linked) {
                  const lines = yield* itemLinesFor(files, snapshot.todo.config, updated)
                  yield* writeTodo(replaceItem(snapshot.todo, item, lines))
                } else if (item.path !== undefined) {
                  yield* files.write(
                    item.path,
                    entry.source === undefined
                      ? formatTaskFile(taskFileFor(updated))
                      : updateTaskFile(entry.source, changesOf(valid)),
                  )
                  if (updated.title !== item.title) {
                    yield* writeTodo(setItemHead(snapshot.todo, item, id, updated.title))
                  }
                }
                return updated
              }),
            ),
          ),
        ),

      move: (id, placement) =>
        validate(Placement, placement).pipe(
          Effect.flatMap((where) =>
            mutate((snapshot) =>
              Effect.gen(function* () {
                const entry = yield* findOpen(snapshot, id, "move")
                if (where.before === id || where.after === id) {
                  return yield* new ValidationError({
                    issues: [`task ${id} cannot be placed next to itself`],
                  })
                }
                const { item } = entry
                const rest = parseTodoFile(removeItem(snapshot.todo, item))
                const target = yield* resolve(rest, where)
                const task: Task = { ...entryTask(entry), group: target.group }
                let lines = snapshot.todo.text.lines.slice(item.start, item.end)
                const { tasksDir } = snapshot.todo.config
                if (
                  target.group !== entry.section.name &&
                  item.linked &&
                  item.path !== undefined &&
                  dirname(item.path) === groupDir(tasksDir, entry.section.name)
                ) {
                  const path = joinPath(groupDir(tasksDir, target.group), basename(item.path))
                  yield* files.move(item.path, path)
                  lines = linkedItemFor(task, path)
                }
                yield* writeTodo(insertItem(rest, target.group, target.index, lines))
                return task
              }),
            ),
          ),
        ),

      complete: (id) =>
        mutate((snapshot) =>
          findOpen(snapshot, id, "complete").pipe(
            Effect.flatMap((entry) => completeEntry(files, snapshot, entry)),
          ),
        ),

      reopen: (id) =>
        mutate((snapshot) =>
          Effect.gen(function* () {
            const done = snapshot.done.find((candidate) => candidate.id === id)
            if (done === undefined) {
              return yield* Effect.fail(
                snapshot.entries.some((entry) => entry.id === id)
                  ? new InvalidTransition({ id, status: "open", operation: "reopen" })
                  : new TaskNotFound({ id }),
              )
            }
            const task = doneTask(done)
            const section = snapshot.todo.sections.find(
              (candidate) => candidate.name !== undefined && candidate.name === task.group,
            )
            const group = section?.name
            const reopened: Task = { ...task, status: "open", completedAt: undefined, group }
            const path = taskPath(snapshot.todo.config.tasksDir, group, id, reopened.title)
            // The done file is the commit point, so it is deleted last (spec §2.10).
            const end = (section ?? snapshot.todo.sections[0])?.items.length ?? 0
            yield* writeTodo(insertItem(snapshot.todo, group, end, linkedItemFor(reopened, path)))
            yield* files.write(
              path,
              updateTaskFile(done.source, { group: null, completedAt: null }),
            )
            yield* files.remove(done.path)
            return reopened
          }),
        ),

      remove: (id) =>
        mutate((snapshot) =>
          Effect.gen(function* () {
            const entry = snapshot.entries.find((candidate) => candidate.id === id)
            if (entry !== undefined) {
              yield* writeTodo(removeItem(snapshot.todo, entry.item))
              if (entry.item.linked && entry.item.path !== undefined)
                yield* files.remove(entry.item.path)
              return
            }
            const done = snapshot.done.find((candidate) => candidate.id === id)
            if (done === undefined) return yield* new TaskNotFound({ id })
            yield* files.remove(done.path)
          }),
        ),

      renameGroup: (from, to) =>
        mutate((snapshot) =>
          Effect.gen(function* () {
            const section = snapshot.todo.sections.find(
              (candidate) => candidate.name !== undefined && candidate.name === from,
            )
            if (section === undefined) return yield* new GroupNotFound({ name: from })
            const name = yield* validate(Label, to)
            if (name === from) return
            const taken = snapshot.todo.sections.some(
              (other) =>
                other !== section &&
                other.name !== undefined &&
                (other.name === name || groupSlug(other.name) === groupSlug(name)),
            )
            if (taken)
              return yield* new ValidationError({ issues: [`group ${name} already exists`] })

            const { tasksDir } = snapshot.todo.config
            const oldDir = groupDir(tasksDir, from)
            const newDir = groupDir(tasksDir, name)
            let text = renameSection(snapshot.todo, from, name)
            if (oldDir !== newDir && (yield* files.exists(oldDir))) {
              const moveWhole = !(yield* files.exists(newDir))
              if (moveWhole) yield* files.move(oldDir, newDir)
              while (true) {
                const todo = parseTodoFile(text)
                const item = allItems(todo).find((candidate) =>
                  candidate.path?.startsWith(`${oldDir}/`),
                )
                if (item?.path === undefined || item.id === undefined) break
                const path = `${newDir}/${item.path.slice(oldDir.length + 1)}`
                if (!moveWhole) yield* files.move(item.path, path)
                text = replaceItem(
                  todo,
                  item,
                  formatLinkedItem({ id: item.id, title: item.title, path }),
                )
              }
            }
            yield* writeTodo(text)
          }),
        ),

      comment: (id, input) =>
        validate(CommentInput, input).pipe(
          Effect.flatMap((valid) =>
            mutate((snapshot) =>
              Effect.gen(function* () {
                const task = yield* findTask(snapshot, id)
                const comment: Comment = {
                  author: valid.author,
                  body: valid.body,
                  at: yield* DateTime.now,
                }
                const done = snapshot.done.find((candidate) => candidate.id === id)
                const entry = snapshot.entries.find((candidate) => candidate.id === id)
                if (done !== undefined) {
                  yield* files.write(done.path, prependComment(done.source, comment))
                } else if (
                  entry?.item.linked &&
                  entry.item.path !== undefined &&
                  entry.source !== undefined
                ) {
                  yield* files.write(entry.item.path, prependComment(entry.source, comment))
                } else if (entry !== undefined) {
                  // An inline task, or a link to a missing file: (re)write the file with the comment.
                  const withComment: Task = { ...task, comments: [comment, ...task.comments] }
                  const path = entry.item.linked ? entry.item.path : undefined
                  const lines = yield* itemLinesFor(files, snapshot.todo.config, withComment, path)
                  if (!entry.item.linked)
                    yield* writeTodo(replaceItem(snapshot.todo, entry.item, lines))
                }
                return comment
              }),
            ),
          ),
        ),

      diagnostics: () => Effect.map(read, (snapshot) => snapshot.diagnostics),
    })
  })

/** A `TodoStore` over the list at `options.root`. */
export const layer = (
  options: Options,
): Layer.Layer<TodoStore, never, FileSystem.FileSystem | Path.Path> =>
  Layer.effect(
    TodoStore,
    Effect.flatMap(makeFiles(options.root), (files) => makeStore(files, options)),
  )
```

```ts
import { Effect, FileSystem, Option, Path } from "effect"
import { formatTodoFile } from "../markdown/index.ts"
import { StoreError } from "../spec/index.ts"
import { makeFiles } from "./files.ts"
import { todoPath } from "./snapshot.ts"

/**
 * Finds the list for `cwd`: walking up from `cwd`, the first directory level
 * with `todo/TODO.md` or `TODO.md` wins, `todo/TODO.md` first. Returns the
 * list root (the directory holding `TODO.md`).
 */
export const findListRoot = (
  cwd: string,
): Effect.Effect<Option.Option<string>, StoreError, FileSystem.FileSystem | Path.Path> =>
  Effect.gen(function* () {
    const fs = yield* FileSystem.FileSystem
    const path = yield* Path.Path
    let dir = path.resolve(cwd)
    while (true) {
      for (const candidate of [path.join(dir, "todo"), dir]) {
        const found = yield* fs.exists(path.join(candidate, todoPath)).pipe(
          Effect.mapError(
            (error) =>
              new StoreError({
                message: `could not look for a list: ${error.message}`,
                cause: error,
              }),
          ),
        )
        if (found) return Option.some(candidate)
      }
      const parent = path.dirname(dir)
      if (parent === dir) return Option.none()
      dir = parent
    }
  })

export interface InitOptions {
  readonly title: string
  readonly description?: string
}

/** Creates a list at `dir`, creating the directory. Fails if `dir` already has a `TODO.md`. */
export const initList = (
  dir: string,
  options: InitOptions,
): Effect.Effect<void, StoreError, FileSystem.FileSystem | Path.Path> =>
  Effect.gen(function* () {
    const files = yield* makeFiles(dir)
    if (yield* files.exists(todoPath)) {
      return yield* new StoreError({ message: `${dir} already has a ${todoPath}` })
    }
    yield* files.write(todoPath, formatTodoFile(options))
  })
```

````markdown
## Reads and writes

- **Reads never write.** `load`, `get`, `listDone` and `diagnostics` read a
  snapshot of the list: `TODO.md`, the linked task files, the done
  directory, and the file names in the tasks directory and its group
  directories. Hand-edited state (a missing ID, a ticked box, stale link
  text, an interrupted completion) is reported as diagnostics.
- **Every mutation runs the same pipeline:**

  ```
  lock → normalize (spec §2.11) → read a snapshot → edit → write files → unlock
  ```

- **No cache.** Hand edits made between commands are always seen.
- **Atomic files.** Each write goes to a temporary file, then is renamed over
  the original.

  mutation, so concurrent processes (typically agents) cannot lose each
  other's writes. A lock older than `staleAfter` was left by a crashed
  process and is taken over.
- **Crash safety.** Multi-file operations follow the order in spec §2.10. For
  `complete` and `reopen`, the done file is the commit point, so an
  interrupted operation is finished or rolled back by the next change.

- `broken-link`
- `orphan-file`: task files directly in the tasks directory or in a group
````
