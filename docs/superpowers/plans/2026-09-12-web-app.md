# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the private `@lemol/todo-md-web` workspace app: a local, progressively enhanced web UI over one todo.md list with board, task, done, diagnostics, mutations, and live file refresh.

**Architecture:** `apps/web/server.ts` is the sole production composition root. It wires `FsTodoStore` and `TodoService` into one `ManagedRuntime`, creates the file watcher, and passes adapter-neutral capabilities into a Remix router. Server-rendered GET pages and POST/redirect forms remain fully usable without JavaScript; one browser entry adds SSE-driven region refresh without duplicating route rendering.

**Tech Stack:** Bun 1.4, TypeScript 7, Effect `4.0.0-rc.108`, `@effect/platform-bun` `4.0.0-rc.108`, Remix `3.0.0-rc.2`, Remix UI, `bun:test`, mdast → hast → HTML.

**Spec:** [`docs/superpowers/specs/2026-09-12-web-app-design.md`](../specs/2026-09-12-web-app-design.md)

## Global Constraints

- `docs/spec.md` remains the behavioral source of truth; do not change core semantics in the web app.
- The app is a private workspace member at `apps/web`, and the published root package remains independent of Remix.
- Pin `remix` exactly to `3.0.0-rc.2`; pin `effect`, `@effect/platform-bun`, and `@effect/platform-node-shared` exactly to `4.0.0-rc.108`.
- Runtime app code imports `@lemol/todo-md/spec`, `@lemol/todo-md/core`, and `@lemol/todo-md/fs` by package name. It never imports `@lemol/todo-md/markdown` or `@lemol/todo-md/spec/testing`.
- Read `node_modules/effect/AGENTS.md` completely before writing Effect code. For Remix APIs, the installed `node_modules/remix/src/<subpath>/README.md` for `3.0.0-rc.2` overrides the Remix skill.
- Every URL in app code and tests comes from `routes.*.href()`.
- Every mutation is an HTML form POST followed by a `303` redirect; JavaScript is enhancement only.
- Keep the router adapter-neutral. Only `server.ts` imports `FsTodoStore` and `@effect/platform-bun`.
- Markdown rendering must omit raw HTML: use `fromMarkdown` → `toHast` without `allowDangerousHtml`, then `toHtml` without `allowDangerousHtml`.
- Bind to `127.0.0.1` and port `4400` by default. Reject foreign Host headers and unsafe cross-origin browser writes.
- Biome formatting is double quotes, no semicolons, 2 spaces, width 100.
- `bun run check` is the gate before each commit.

- [ ] **Step 3: Implement the adapter-neutral middleware contracts**

```ts
export interface ListChanges {
  subscribe(listener: () => void): () => void
}

export interface TodoRuntime {
  runPromise<A, E>(effect: Effect.Effect<A, E, TodoService>): Promise<A>
}

export type TodoResult<A, E> =
  | { readonly ok: true; readonly value: A }
  | { readonly ok: false; readonly error: E }

export const runTodo = async <A, E>(
  context: { get(key: typeof todoRuntimeContext): TodoRuntime },
  use: (todo: TodoService["Service"]) => Effect.Effect<A, E>,
): Promise<TodoResult<A, E>> => {
  const runtime = context.get(todoRuntimeContext)
  const result = await runtime.runPromise(
    Effect.either(TodoService.use(use)),
  )
  return Either.isRight(result)
    ? { ok: true, value: result.right }
    : { ok: false, error: result.left }
}
```

`Effect.either` converts only typed failures. A defect still rejects `runPromise` and is mapped to 500 at the controller boundary.

`loadTodo({ runtime, capabilities, author })` sets `todoRuntimeContext`, `capabilitiesContext`, and `authorContext`; `loadChanges(changes)` sets its own typed key. Keeping the default author on request context lets the task controller prefill comment forms without importing server configuration. `taskId` strips decimal leading zeroes exactly like `src/cli/context.ts`.

- [ ] **Step 4: Implement Host and cross-origin middleware**

`localOnly(hosts)` parses the `Host` header without trusting the request URL, removes brackets from IPv6, lowercases DNS names, and compares only the hostname to the supplied allowlist. Missing/malformed/foreign Host returns `new Response("Forbidden", { status: 403 })`. Configure `hosts` with `localhost`, `127.0.0.1`, `::1`, and the selected bind host.

Order middleware as:

```ts
[
  localOnly(options.hosts),
  cop(),
  compression(),
  formData(),
  session(cookie, createMemorySessionStorage()),
  asyncContext(),
  loadTodo(options),
  loadChanges(options.changes),
  loadAssetEntry(assets),
  render({ assets }),
]
```

Create the cookie with a per-router random secret when `sessionSecret` is absent and with `{ httpOnly: true, sameSite: "lax", path: "/", secrets: [secret] }`. Sessions contain only the `flash` key.

- [ ] **Step 5: Create the asset server and router composition**

Use `createAssetServer` with `rootDir` equal to `apps/web`, `basePath: "/assets"`, `allowFiles: ["app/routes.ts", "app/ui/styles.css", "app/**/public/**"]`, `allowPackages: ["remix"]`, and `denyFiles: ["app/**/*.test.*"]`. Keep stable URLs and no asset watcher; this app is local and has no deploy build. As in mionso's pinned rc.2 app, resolve `remix/package.json`, walk to Bun's `.bun` store, and configure that relative directory as the `npm` mount so browser imports resolve through workspace symlinks. `loadAssetEntry` resolves `assets.getScriptEntry("app/actions/public/entry.ts")` once per request, stores the `ScriptEntry` on context, and exposes `getAssetEntry()` through `getContext()` for the document component.

Implement the final shared responder now: `TaskNotFound` renders 404; `GroupNotFound`, `Unsupported`, and an unclaimed `ValidationError` render 400; `StoreError` renders 500; add/edit intercept `ValidationError` for their 422 forms; lifecycle actions intercept `InvalidTransition` for flash redirects; an unknown typed value or caught defect renders 500. This lets every later controller use the final error path from its first implementation.

Map `routes` to the root controller and `routes.tasks` to the task controller. Initially return small 200/501 responses so the focused middleware tests can pass. Export `close()` from the router composition to close the asset server during server shutdown and tests.

```ts
  "Cache-Control": "no-cache, no-transform",
  Connection: "keep-alive",

```

- [ ] **Step 4: Implement browser refresh without a parallel renderer**

The installed rc.2 runtime has `app.frames.top.reload()` and named frame handles, but this document does not have a non-recursive named-frame route. Use the spec-approved fetch fallback:

1. The module script rendered by `Document` calls `run({ loadModule: (url, name) => import(url).then((module) => module[name]) })` to boot Remix UI.
2. One capture-phase `input`/`change` listener marks the current document dirty.

4. If dirty, unhide `[data-reload-notice]` and do not fetch.
5. Otherwise fetch `location.href` with `Accept: text/html`, parse with `DOMParser`, and replace the current `[data-live-region]` with the fetched one.
6. Reset dirty state after replacement. A failed fetch leaves the current DOM intact and reveals the reload notice.
